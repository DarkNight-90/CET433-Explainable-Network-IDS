## Explicit M03 route, after approval only

Reuse the accepted command with the additional arguments
`--execute-m03 --run-id <new-run-id>`. Use a new identifier for each
attempt. The execute flag is absent by default. The runner verifies the
snapshot and compiles only explicitly marked model cells. It does not
execute the complete notebook or the SHAP cells.

The selection phase receives training features and the frozen plan only.
The verified plan maps original fit rows directly to five `PredefinedSplit`
holdouts. No CV regeneration, deduplication, row sampling, or MLP early
stopping is performed. The operative baselines, tree search, fold-local
preprocessing, multiclass comparison, and validation-only threshold logic
come from the M02.2 workflow. The exploratory duplicate baseline cells
are excluded from the run.

After selection, persist the validation threshold, joint feasibility,
model configuration, and both selected model artifacts. Only then verify
and open the official test CSV and run the frozen final report cell.
It reports unmodified official observations and the exact-feature-unseen
stratum relative to internal fit. A deduplicated evaluation is separately
labeled as unperformed. See [the M02.2 protocol](m02.2-split-protocol.md).

A new persistent `runs/<run-id>/` directory contains `run_started.json`,
`split_assignments.json`, `selection.json`, `ids_model.joblib`,
`attack_family_model.joblib`, `results.json`, and `run_manifest.json`.
Creation refuses existing run IDs and file paths. A missing final manifest
indicates an incomplete run. Preserve it for diagnosis and use a new ID
when retrying. The final manifest binds source, runtime, lock, datasets,
full CV assignment, model parameters, threshold, and output paths.
