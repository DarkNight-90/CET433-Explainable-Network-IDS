## Run records

A new directory under `runs/<run-id>/` contains the verified assignment,
run configuration, per-model fit attempt and result records, validation
reports, and model artifacts with SHA-256 digests. Treat a valid
`run_manifest.json` with `status: complete` as the completion record.
An exception or handled keyboard interruption writes `run_failure.json`.
A killed process, VM reset, or lost mount can leave only partial records.
Without a valid completion manifest, treat the run as incomplete and consult
the per-model records. A fit-started record without a fit result identifies
an attempted or in-flight operation whose outcome and duration are unknown.
Preserve incomplete directories and use a new run ID for an approved retry.
